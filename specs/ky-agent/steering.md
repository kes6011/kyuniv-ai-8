# steering.md — FocusLog Agent 전역 규칙

이 파일은 Agent의 모든 컴포넌트에 적용되는 불변 규칙을 정의한다.
`requirements.md`, `design.md`, `tasks.md`, `CHECKLIST.md`의 모든 판단은 이 규칙을 우선한다.

---

## 1. 사용자 자율성 원칙 (최우선)

- Agent는 어떠한 경우에도 사용자의 행동을 **강제로 차단**하지 않는다.
- 앱 차단은 항상 사용자가 즉시 해제할 수 있어야 한다.
- 차단 해제 요청이 연속 2회 이상 발생하면 해당 세션의 차단을 완전히 해제하고 `override_log`에만 기록한다. 이후 동일 세션 내에서 차단을 재시도하지 않는다.
- 팝업·알림은 사용자가 무시하거나 닫을 수 있어야 하며, 3회 이상 무시 시 해당 세션에서 동일 유형 알림을 재발송하지 않는다.

---

## 2. 비용 상한

- Claude API 호출은 **세션 종료 후 리포트 생성**에만 허용한다.
- 실시간 이탈 탐지·분류·집중도 계산은 모두 **온디바이스 모델** 전담이다.
- Claude API 일일 최대 호출 횟수: **5회/사용자**.
- 5회 초과 시 로컬 통계 기반 간략 리포트를 생성하고 API 호출을 생략한다.

---

## 3. 도구 화이트리스트

아래 도구 이외의 외부 서비스 호출은 금지한다.

| 도구 | 용도 |
|------|------|
| `UsageStatsManager` | 앱 전환 이벤트 수집 |
| `AccessibilityService` | 화면 이벤트·포그라운드 앱 감지 |
| `MediaSession API` | 유튜브 영상 제목 수집 |
| `DevicePolicyManager` | 앱 일시 차단 (5분, 사용자 해제 가능) |
| `로컬 Notification` | 알림 발송 (포모도로 재시작, 휴식 권고) |
| `Claude API` | 세션 종료 리포트 생성 전용 |
| `온디바이스 SQLite` | 세션·이탈 이벤트 로컬 저장 |

---

## 4. 사람 개입이 필요한 조건

다음 조건 중 하나라도 충족되면 Agent가 자동 판단을 중단하고 사용자에게 확인을 요청한다.

| 조건 | 조치 |
|------|------|
| 온디바이스 분류 신뢰도 < 0.60 | "이 영상이 [과목]과 관련 있나요?" 1문항 팝업 |
| 앱 차단 해제 요청 ≥ 연속 2회 | 차단 완전 해제 + `override_log` 기록 |
| 세션 데이터 필수 필드 누락 | 오류 명시 + `fallback_log` + 수동 확인 요청 |

---

## 5. 분류 암묵 규칙 (도메인 컨텍스트)

- **유튜브 = 항상 방해가 아니다**: 제목·채널명에 현재 과목명 또는 [강의, 개념, 정리, 문제풀이, 수업] 키워드가 포함되면 `study_related`로 분류하며 집중도를 차감하지 않는다.
- **카카오톡 = 항상 방해가 아니다**: 체류 시간 ≤ 60초이면 `habitual_check`(가중치 1.5), 체류 > 60초이면 `avoidance_chat`(가중치 1.8)으로 구분한다.
- **개인화 우선**: 동일 앱이라도 사용자가 이전에 "학습 관련"으로 확인한 채널은 이후 세션에서 자동으로 `study_related`로 분류한다.

---

## 6. 집중도 점수 산식 고정

```
focus_score = max(0, 100 - Σ(weight_i × duration_min_i))
```

가중치는 아래 값으로 고정하며, 임의 변경 금지:

| 이탈 유형 | 가중치 |
|---------|------|
| `study_related` | 0.0 |
| `habitual_check` | 1.5 |
| `avoidance_entertainment` | 2.0 |
| `shopping` | 1.8 |
| `avoidance_chat` | 1.8 |
| `unknown` | 1.0 |

---

## 7. 응답 시간 SLA

| 작업 | 최대 허용 시간 |
|------|-------------|
| 앱 전환 감지 → 집중도 갱신 | 3초 |
| 분류 신뢰도 < 0.60 → 팝업 표시 | 3초 |
| 오류 입력 → 오류 응답 반환 | 500ms |
| 세션 종료 → 리포트 생성 완료 | 30초 |
| Claude API 타임아웃 → 로컬 리포트 폴백 | 5초 |

---

## 8. 데이터 프라이버시 원칙

- 수집된 앱 로그·미디어 제목은 온디바이스에만 저장하며, 클라우드로 전송하지 않는다.
- Claude API에 전달하는 데이터는 익명화된 집계 통계(이탈 유형별 시간 합계, 집중도 타임라인)만 포함한다. 영상 제목 원문, 채팅 내용은 포함하지 않는다.
- 세션 로그 보관 기간: 30일 (이후 자동 삭제).
